# Beta 2: outline and walls before regions

The default image/PDF import runs locally, with no Luna request. A bounded worker extracts long dark wall strips, bridges collinear gaps only when proposing the outer footprint, and offers one editable orthogonal footprint plus physical wall proposals. Printed text is data, never instructions. Manual tracing and the previous experimental Luna path remain explicit choices in File → Import method.

Set scale from a known printed dimension. The drawing does not display physical dimensions until calibrated. Correct the footprint using its rectangle handles or add room area; add, edit or remove physical walls using the existing controls. Draw dashed region dividers across doorways or open-plan boundaries that should separate labels without becoming 3D walls. Both kinds of boundary snap to existing coordinates.

Generate regions subdivides the union footprint at boundary coordinates and finds connected components. It keeps concave shapes, courtyards and disconnected islands in the edited footprint, preserves total area and existing physical walls/openings, and rejects excessive fragmentation rather than discarding slivers. Open door gaps stay connected. Generation replaces region names/joins, with one-step Undo. Combine and rename the resulting regions before explicit 3D review. Dividers persist only in the editable Studio draft; they are never sent to physical wall construction. Calibration metadata participates in Undo with the geometry.

The automatically proposed footprint is an envelope, not a ground-truth building perimeter. It can bridge courtyards, miss thin glazing, include linework outside the home or miss diagonal/curved walls. The user must correct it; geometry remains orthogonal. Wall proposals can miss openings and thin partitions. This flow deliberately relies on human boundary corrections instead of semantic room guessing.

Validation: focused tests cover L-shaped entries, open door connectivity, non-physical dividers, exact area conservation, disconnected footprint parts, holes, rounding, malformed/tiny partitions, persistence, and the import/calibrate/divide/generate/combine/undo flow. On the user's apartment in the local browser, adding the missing closet-side wall and dividers at the main-hall and bathroom doors produced a bedroom region containing its L-shaped entry, with the bathroom separate. This involved manual corrections and is not an automatic recognition accuracy claim. No paid model tests were used.
