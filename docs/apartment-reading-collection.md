# Apartment and reading collection

Forty original Blender models extend the existing collection. Existing catalog IDs and fixture dimensions remain unchanged. Sources are retained in `assets-source/blender`, generated by `tools/blender/build_apartment_collection.py`; GLBs and lossless WebP previews use the same IDs. `assets-source/apartment-model-audit.json` records dimensions, triangles, editable parts and exported size.

## Review and performance

All forty Blender previews were reviewed. Review corrections included fabric foundations under mat pile, smoother opal shading, a connected globe pedestal and separating the C-table inlay from the steel top to avoid coplanar flicker. Static parts are consolidated for browser export while sources retain individual editable construction. Production processing shares unchanged textures and compresses geometry losslessly. Collection tests enforce dimensional bounds, grounding, fewer than 60,000 triangles per piece, fewer than 20 loaded meshes per piece, source/preview presence, tabletop support, shower serialization/history and isolated globe motion/disposal.
