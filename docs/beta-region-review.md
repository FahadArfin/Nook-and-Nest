# Beta 2: region-first floor-plan review

Import and Reanalyze use Luna in a bounded two-pass pipeline. The inventory includes unlabeled connectors. Geometry returns separate editable orthogonal regions (adjacent rectangular parts encode a concave polygon), with independent physical wall spans. Regions do not automatically create interior walls. Cache version: `luna-regions-v3`.

A bounded local grid search proposes enclosed uncovered pockets as Unassigned regions. Existing regions are never resized or relabeled by that search. Solid source wall strips and model-verified wall spans act as barriers. Non-rectangular erosion components are decomposed into unions of fully black kernels, so broad L/T corners retain real walls without filling their empty bounding-box corners. Legacy unverified broad boxes remain excluded. Exterior-connected components, wall-width slivers, excessive geometry and large pockets are rejected. These are unverified proposals, not ground truth.

After calibration, the editor opens Combine mode. Select adjacent regions on the canvas or list, enter a room name/type, and Combine selected. The exact union outline is preserved; authored walls and openings survive. A generated divider supporting an existing opening is retained. One Undo restores each join. Review & create 3D remains explicit. Room labels no longer imply physical wall removal.

Current limits: orthogonal stepped geometry only, not arbitrary diagonal/curved polygons. Luna can misread closets, wall spans and scale, and can omit exterior-connected areas. Inspect dashed region outlines against the uploaded image, adjust or delete incorrect regions, and review physical walls separately. Dimensions remain subject to the existing calibration/conflict review.

Validation: unit tests cover region independence, L-shaped union, protected bathroom geometry, wall/opening retention, save/reopen, uncovered-pocket proposals and exterior rejection. UI tests exercise import -> Combine -> Undo -> Reanalyze without changing the active 3D home. Two live analyses used the supplied apartment privately; the second still omitted the master entry, which the deterministic pocket stage recovered as a separately selectable region. No claim of general accuracy improvement is made from one image. Private scans, outputs, credentials and the browser harness are excluded from release artifacts.

Wall-strip correction: regression coverage includes an inset main-room edge where the previous broad-box filter leaked an L-shaped pocket to the exterior. Eight saved apartment detections produced entry-pocket proposals after this correction; these are same-image replays, not eight independent floor plans.
