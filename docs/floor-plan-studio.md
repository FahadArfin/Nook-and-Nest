# Floor plan studio

The Floor plan button beneath the camera-view controls opens a separate, uncommitted top-down editor. Upload PDF, PNG, JPEG or WebP files up to 25 MB, choose a PDF page, rotate the reference, and calibrate a known measurement. References render locally using PDF.js or the browser image decoder; their contents, scripts and links are never treated as instructions. Uploaded documents and reference images are not sent to the project server or included in shared projects.

Draw rectangular room areas, combine open areas for irregular orthogonal footprints, name/type rooms, drag them, and edit exact dimensions in metres, decimal feet or millimetres. Draw extra inside walls or enable a room's dividers. Place kitchen, bathroom and laundry fixtures plus doors/windows from the existing catalog. Doors/windows use the same wall snapping and aperture generation as the 3D editor. This is manual tracing, not automatic image recognition. Curved and diagonal footprint boundaries are not supported by this first editor.

Review and explicitly confirm before replacing the active floor with a 3D home. Loose furniture is excluded; manually positioned service fixtures and openings remain. The review explicitly warns that stair connections to the replaced floor are removed. Other floors and their unrelated contents remain. Each conversion uses the existing stale-base guard, validation, one-step undo and local autosave. Online saving remains explicit. Room labels/types persist through JSON export, cloud saves and sharing using optional schema-version-1 metadata; changed 3D architecture invalidates stale room zones.

Auto furnish creates a separate unsaved 3D preview for Living, Bedroom, Dining and Office areas. It uses full-size catalog pieces, conservative wall/footprint checks, existing-item spacing and door clearance reservations, and groups tables/chairs and beds/nightstands where they fit. Service rooms remain untouched. Items that do not fit are reported, not scaled. Applying adds independent placements in one undo step. This is a bounded suggested arrangement; users should review circulation and facing. It is not a whole-library style optimizer.

Validation covers exact dimensions, L-shaped unions, shared dividers, save/share round-trips, malformed files and metadata, fixture snapping, floor preservation, stale edits, one-step undo, calibration/tracing gestures, draft history, automatic furnishing preview/apply/discard, clearances and oversized furniture. A real scanned PDF was also rendered with the installed PDF.js engine during development. The private source document is not included in this repository.
