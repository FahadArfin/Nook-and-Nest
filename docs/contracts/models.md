# Models contracts

Current requirements grouped from the original guide. Later explicit directions take precedence over older batch notes. Read the latest-wins rules in AGENTS.md first.

WebMCP direction: agents should be able to creatively furnish the current apartment through native, structured page tools, including batch placement, real measurements, independent material colors and supported tabletop/shelf decoration. Preserve the human editor and saved schema. Default to an unsaved reviewable design; offer explicit per-tab/project permission for direct agent application, a pause control and one-step undo for each arrangement. Do not expose account details, other private projects, cloud saves or public sharing through furnishing tools. Reject stale proposals and malformed inputs before mutation. Use native document.modelContext with feature detection, lifecycle cleanup and real browser-tool contract tests; unsupported browsers retain manual editing.

Furniture must use original editable Blender sources exported to GLB, with the existing Babylon.js procedural assemblies retained only as loading/error fallbacks. Keep a cohesive cozy handcrafted low-poly language: chunky chamfered primary forms, layered secondary construction, restrained decorative detail, visible wood and fabric texture, warm rough shared materials, and subtle variation. Preserve millimetre-accurate dimensions, catalog and placement IDs, saved schema compatibility, picking, dragging, snapping, and undo/redo.

Every catalog piece must read immediately as its named real-world furniture type, with its own silhouette and construction details. Do not use scaled spheres or ellipsoid "blobs" as upholstered furniture, plant clusters, pet beds, or rugs. Prefer thick frames, rounded-rectangular cushions, visible legs and joints, layered panels, warm muted colors, subtle bevels, slight asymmetry, and a few legible decorative details. Sofa-family upholstery should use clean matte color with only restrained surface grain, not coarse basket-weave texture; avoid default loose side cushions and contrasting arm caps. Avoid razor-sharp CAD boxes, photorealism, glossy plastic, extremely thin parts, excessive polygons, and perfect symmetry.

After placement confirmation, furniture should be deselected. Clicking any placed furniture must reopen a model-anchored editing toolbar with remove, rotate-left, done, rotate-right, and direct color swatches; keep the detailed inspector synchronized as the secondary precision editor.

Each floor layer must offer cozy saved wall and floor finishes. Wall choices should include restrained paint colors, brick, stone, and wallpaper; floor choices should include wood, laminate, tile, and carpet. Keep texture detail soft and handcrafted rather than photorealistic, and retain finish changes in undo/redo, autosave, export, and share links. Expand the décor catalog with distinctive rugs built from editable Blender sources, not procedural-only browser shapes.

Keep the catalog broad within each furniture type: sofas, beds, desks, and side tables should offer genuinely different recognizable constructions, not scaled copies. Include TV/media furniture and a modular kitchen family with appliances, base and wall cabinets, counters, sinks, and islands. Counter-capable kitchen pieces must save an independently selectable granite, marble, laminate, or concrete worktop finish on each placement.

Windows should offer distinct original Blender-built casement, sash, picture, arched, bay, and awning styles. Use the existing reversible placement toolbar, snap windows to continuous outer or interior walls, cut visible wall openings, and support frame colors, dimensions, sill height, and a wall-aligned facing flip. Preserve window transforms through undo, local saving, export, and sharing.

Offer varied coffee tables and computer desks, plus standalone monitors, gaming and office chairs, PC towers, mini PCs, laptops, tower fans and pedestal fans. Computer accessories must remain independently placeable and support tabletop snapping plus manual height adjustment; do not bake them into desk models. Keep original Blender sources, real dimensions, color variants and model thumbnails for the expanded collection.

Bathroom variety should include different mirrors, pedestal/wall/vessel sinks, single/double/floating vanities, two-piece/one-piece/wall-hung toilets, standing showers, alcove baths and freestanding baths. Base the types on researched fixtures but create original Blender models. Use genuine recessed basins/tubs, translucent shower glazing, adjustable wall-mount heights, tintable exterior/frame materials and selectable vanity worktops. Treat fixtures as layout aids, not plumbing or code validation.

Keep the growing furniture library easy to navigate rather than compressing more categories into a tiny horizontal strip. Use labeled category and furniture-type filters, whole-library search, browser-local favorites, and a wider optional browsing panel. Preserve the cozy design language, visible model names/dimensions, and reversible drag/keyboard placement; library navigation and favorites must never change the apartment or undo history.

Latest expansion direction: preserve camera framing on selection/edits, start mouse placement only after dragging into the scene, and keep walls solid unless the explicit transparency toggle is enabled. Offer independent per-material colors and complete rendered catalog previews. Floor actions belong beside floor tabs. Night mode should retain readable controls.

Wall-mounted kitchen pieces sit against solid wall faces without cutting apertures; backsplash tile and grout colors remain independent. Pendants need an editable hanging height.
